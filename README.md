# BamEx Stranded Deep Mod Catalog

Public stable release catalog for BamEx Stranded Deep mods.

The catalog is intended for use by Stranded Deep Mod Manager and other compatible tools.

## Stable catalog

Current public catalog:

`stable/catalog.json`

SHA-256 checksum:

`stable/catalog.json.sha256`

Only publicly released and supported stable packages are included.

## Current stable packages

- Stranded Deep Better Meat
- Stranded Deep Infinite Fire Torch
- Stranded Deep Mod Settings
- Stranded Deep Natural Regrowth
- Stranded Deep Split Map
- Stranded Deep Table Storage
- Stranded Deep UI Scaler

Development and unpublished mods are intentionally excluded from the public stable catalog.

## Distribution

Each package entry points to a versioned GitHub Release asset and includes its expected SHA-256 checksum.

The individual mods remain independently installable without the Mod Manager.
